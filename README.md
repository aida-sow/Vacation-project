# Mon projet

Ce projet vise a afficher une page web montrant une image en dessous d'un petit paragraphe.

## Ouvrir le projet

Pour ouvrir la page sur votre machine vous pouvez : 
- Cliquer sur le boutton vert "Code" puis sur "Download ZIP" pour télécharger le projet sous format d'un fichier ZIP
- Décompresser le fichier ZIP puis ouvrir le dossier extrait 
- Enfin faire un double-clique sur `index.html` 

## Technologies utilisées 

HTML5 Sémantique
